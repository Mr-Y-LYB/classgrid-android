修复了两个排程问题：返回前台时取消到点提醒后不再补排，以及联网检查更新阻塞本地提醒队列。现在网络任务与本地任务分开；已发送的课程记录用于去重。

系统设置中的“强行停止”会暂停应用并取消系统待执行任务，需要用户再次打开应用。模拟器结果不能替代各厂商手机后台限制的实机验证。
